Chatbot AI (DeepSeek)

Conecta el bot conversacional con un workflow de n8n que llama a DeepSeek. Entiende lenguaje natural, mantiene contexto, y puede navegar al formulario automáticamente.

@if (bot.mode() === 'ai' && bot.aiWebhookUrl()) { ● ACTIVO } @else { ○ INACTIVO }

AI: ~$0.14 por 1M tokens. Más inteligente pero requiere API key.

Workflow separado del de notificaciones. Usa barberschedule-ai-chatbot.json.

⚙️ ¿Cómo configuro n8n con DeepSeek?

1. Abre n8n en http://localhost:5678

2. Crea un nuevo workflow → importa el archivo n8n/barberschedule-ai-chatbot.json

3. En el nodo DeepSeek API, configura credencial Header Auth:

Name: Authorization
Value: Bearer TU_API_KEY_DE_DEEPSEEK

4. Activa el workflow → copia la URL del webhook → pégala arriba

5. Cambia el modo a 🧠 AI y prueba el chat

💡 Tip: la API key de DeepSeek se guarda en n8n, no en el frontend. El frontend solo conoce la URL del webhook.
